# Tasks: Family Tasks

**Input**: Design documents from `/specs/003-family-tasks/`
**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/server-actions.md, quickstart.md — all final

**Tests**: Included and mandatory. The constitution (§II) makes test-first non-negotiable for pure logic, and this phase's pure logic is precisely what can silently produce a wrong board: the widened recurrence grammar, `ruleDatesIn`, the Completed Date cursor, the task expander and its carry-forward pass, the resolution index, the counters, the visibility truth table, the layout decision, the per-device filter store with its storage-unavailable fallback, the reorder reducer and the streak rule. Every server action and every RLS policy is written red in the policies tier (node, against the local **553xx** stack with `.env.local` sourced) before the thing it tests exists. Gesture feel, the completion cross-fade and visual placement are verified by running the app — §II's own carve-out.

**Organization**: Grouped by user story, in the spec's priority order, so each story is an independently verifiable increment. Setup and Foundational block every story; then US1 → US2 → US3 → US4, each reading state the previous one creates.

**Phases 1 and 2 are shipped and live.** Nothing here forks them. Migration **022** widens a CHECK that live calendar events depend on, and it is sequenced **last in the whole phase** (T082) — after the interval-1 equivalence sweep (T015), the stored-corpus round-trip against an untouched schema (T016) and the operator's read-only hosted pre-check (T081). It unblocks nothing: the shipped constraint never mentioned `INTERVAL`, so the database already accepts `INTERVAL=2` (R305, data-model §023).

**Rewards ship in a later phase.** Two reserved `reward_points` columns exist (016, 020) and **no task in this list reads, renders, edits or totals a star value**. T080 audits that (SC-319), locally and ahead of the operator block.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: parallelizable — different files, and nothing it imports belongs to an incomplete task
- **[US#]**: the user story from spec.md the task serves; story-phase tasks only
- **[BLOCKED ON OPERATOR]**: needs the hosted project's access token, the Supabase Dashboard, or physical hardware (the wall tablet, an iPad, a phone). Everything else runs against the local stack (quickstart §3)
